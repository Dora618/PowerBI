# PowerBI

A showcase of **data cleaning**, **transformation**, and **interactive visualization** using Power BI. This project demonstrates how to use **Power Query** to prepare data and build dynamic dashboards.

---

## 🚀 Features

- **Data Cleaning & Preparation**  
  Utilizes Power Query to import, clean, and shape data from an Excel source.

- **Interactive Dashboards**  
  Built with Power BI Desktop (`.pbix`) for real-time insights and interactive exploration.

- **Visual Insights**  
  Combines charts, slicers, and dashboards to uncover patterns and trends.
